# Discover Kharkiv Bot

Телеграм-бот-навігатор Харковом (шкільний проєкт).

## Мови
- 🇺🇦 Українська (за замовчуванням)
- 🇬🇧 English

## Можливості
- Метро: схема, лінії, станції, опис, фото, місця поруч
- Розклад метро на найближчу годину (час Києва)
- Цікаві місця (категорії, фото, станції поруч)
- Сповіщення про повітряну тривогу (Харківська область)
- **Перевірка статусу тривоги зараз** (`/status` або кнопка «Перевірити зараз»)
- Контакти розробника
- Логи дій користувачів (`logging`)
- Статистика для розробника: `/stats` (тільки ADMIN_IDS, не видно звичайним користувачам)

## Встановлення

```bash
pip install -r requirements.txt
```

Файл `.env` (не комітьте його!):
```env
BOT_TOKEN=твій_токен
CONTACT_USERNAME=XDAS2
```

У `config.py` додай свій Telegram ID в `ADMIN_IDS`.

**Важливо:** якщо токен потрапив у архів/git — одразу відклич його в @BotFather і створи новий.

## Запуск

```bash
python main.py
```

## Тривога
Джерело: `https://alerts.com.ua/api/states` (безкоштовно).  
Перевірка кожні 30 секунд. Сповіщення лише тим, хто натиснув «Увімкнути».  
Разовий статус: `/status` або кнопка «🔄 Перевірити зараз».
